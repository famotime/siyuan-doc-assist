# Daily Notes 工作流在思源笔记的应用

双向链接时代的 **Daily Notes 工作流**是思源笔记及类似双链软件中一种核心的笔记管理实践，**其目标是实现快速无压记录**，并与更宏大的笔记管理方法论（如 MOC、渐进式积累）深度结合。这种工作流的价值在于将笔记输入与后期整理分离开来，极大地降低了用户在记录时的心智负担。

## Daily Notes 工作流的核心操作与理念

1. **快速输入与“传递型双链”** :

   - 在 Daily Notes 页面，用户可以**用最快的速度把内容记录下来**，防止遗忘。
   - 记录时，给笔记加上一个**代表其主题归属的锚文本**，这被称为 **“传递型双链”** 。这种链接所指与链接下文内容为上下层关系，即下层内容归属于引用目标。
   - 这种方式使得内容在逻辑上**归属于特定主题**，而**不必在记录当下就考虑精确的分类或存放位置**。
   - 与传统标签相比， **“传递型双链”能够覆盖标签的作用**，并且具备更灵活的转换能力。在思源笔记中，手动输入 `[[ ]]` 并不直接创建双链页面，而是搜索现有块或新建文档，这与 Roam Research 等页名唯一的软件有所不同。
2. **后期整理与“无压”的支撑**:

   - **反链汇总**： Daily Notes 的关键在于其后期整理能力。思源笔记的**反向链接面板（Alt + B）能汇总所有链接到当前文档的笔记**，即便它们分散在不同的 Daily Notes 或其他文档中。
   - **直接拖拽与块引用复用**：反链面板中的内容具备**完整编辑功能**，可以直接修改，也可以**直接拖动到当前文档正文进行整理**。若想保留原始内容在 Daily Notes 中，则可**将块引用拖到正文**。这种“兜底”能力，即通过后期容错率让用户不怕试错、大胆记录，是实现“无压”记录的关键。
   -  **“重述型双链”** ：为了在保留原始上下文的基础上重新表述内容，可以在修改后的内容后面**加上指向原始文本的块引用链接**（如 `*` 锚文本）。这种链接的目的不同于传递型双链的归属或关联型双链的指代。
   -  **“转移引用”功能**：思源笔记的特色功能，允许将**一个块的所有引用关系（反链）转移到另一个目标块上**。这极大地**提高了后期整理的容错率**，用户不必担心前期引用的不准确，可以稍后再进行纠正或重构笔记体系。

## Daily Notes 与笔记管理方法论的结合

Daily Notes 工作流并非孤立存在，它与思源笔记强大的功能和社区发展的多种笔记管理方法论紧密结合，共同构建起灵活的知识体系：

1. **面向主题管理 (MOC - Map of Contents)** :

   - MOC 的核心理念是 **“管理链接而非本体”** 和 **“面向主题地组织信息”** 。
   - Daily Notes 支持**自下而上的积累**（即先记录碎片化笔记），而 MOC 则支持**自上而下的结构化管理**（将零散内容汇总到主题页面）。
   - **列表型 MOC** 是最常用的方式，通过层级列表管理笔记链接。
   - 这种结合**避免了传统文件夹和标签的弊端**，如单分类限制、重复标签问题、整理汇总能力不足等。
2. **数据库的应用**:

   - 思源笔记的数据库功能可以作为**高级表格 MOC**，弥补传统列表型 MOC 在多维度分类筛选方面的不足。
   -  **“添加到数据库”功能**：这是 Daily Notes 工作流中**自下而上积累**的强大工具。用户可以快速新建文档记录，然后通过块标菜单将其**轻松归档到指定数据库**，而无需立即思考其在主题笔记中的位置。这尤其适用于整理**名词概念类笔记**，解决了零散概念难以用列表整理的痛点。
   - **SuperRef 和动态数据库（F-misc 插件）** 进一步增强了 Daily Notes 与数据库的整合。

     - **SuperRef** **将双链（块引）与数据库结合**，赋予双链拓展额外信息的能力，解决了传统反链缺乏语义描述的问题。它适用于**单一主题或概念**的数据库绑定。
     - **动态数据库将标签/关键词与数据库结合**，甚至支持**多对一**的关联，使得思源的三大标记工具（标签、双链、数据库）初步打通。它能够根据关键词自动收集日常札记，并能实现“阶梯式动态数据库”，即通过添加“进阶标签”使笔记同时进入不同功能和结构的数据库，支持多阶段的知识管理。
3. **渐进式学习与积累**:

   - Daily Notes 工作流体现了“渐进式”笔记的理念，即笔记应该是逐步积累完善的。
   - 通过将输入与整理分离，用户可以先进行**碎片化输入**，待认知升级后**再回顾整理**，从而更轻松地完成复杂的组织工作。
   - 这种方法鼓励**主动学习**，而非被动地囤积信息，最终目标是形成**独属于个人的知识体系**。

## 思源笔记中的操作细节与增强

思源笔记提供了丰富的操作和插件来支持 Daily Notes 工作流：

1. **双向链接的创建与查看**:

   - **创建链接**：通过 `[[`​ 或 `【【`​ 输入文字，或选中文字后按 `Alt + [` 来创建引用块。
   - **嵌入块**：通过 `{{`​ 或 `Shift + 拖拽` 创建，内容改动会同步到原文。虽然方便汇总，但也存在修改不便、失效难追溯等问题。
   - **反链面板与浮窗**：`Alt + B` 可打开反链面板，汇总当前文档的引用和提及。鼠标悬浮在反链计数或块上可显示浮窗，并支持直接编辑或跳转。
   - **提及**：系统自动根据关键字（文档名、命名、别名、锚文本等）显示潜在的反向链接。
   - **虚拟引用**：自动探测并标记纯文本中已有的块引锚文本或块命名。
2. **SQL 查询与 Query &amp; View 插件**:

   - 思源笔记内置 SQLite 数据库，允许通过 **SQL 查询** 灵活访问底层数据。
   - **Query &amp; View 插件** 极大增强了 JS 嵌入块和 SQL 查询能力。它提供了 `Query`​ API 进行查询，并支持 `DataView` 对象以列表、表格、卡片、Mermaid 图表（流程图、思维导图、看板）和 ECharts 图表（折线图、柱状图、树形图、关系图）等多种自定义视图渲染查询结果。
   - `fb2p`​（first block to its parent）函数用于**处理容器块与段落块嵌套情况**，将容器块的第一个段落块 ID 重定向到容器块 ID，解决反链查询结果不完整的问题。
   - `pruneBlocks`​ 函数用于**过滤 SQL 搜索结果中的重复块**（如列表、列表项、段落嵌套导致的冗余结果），提高搜索准确性.
3. **模板功能**:

   - 思源笔记支持通过模板快速创建 Daily Notes，并在模板中**预定义 SQL 查询**或利用动态变量（如当前日期 `now`​、文档 ID `.id`）。
4. **其他辅助操作与插件**:

   - **自定义块样式插件**：可将列表转换为表格、导图、看板等多种布局。
   - **转移引用插件**：提供了更细粒度的转移引用功能，允许用户选择性地转移部分引用源。
   - **数据库关联功能**：不同数据库之间可以进行双向关联，使得笔记内容（如概念笔记、主题笔记）可以多维度地链接和管理，形成复杂的知识图谱。

‍

综上所述，思源笔记的 Daily Notes 工作流，在快速无压记录的理念下，通过传递型双链、反链面板整理、转移引用等核心操作，实现了输入与整理的分离。在此基础上，结合MOC、数据库、渐进式学习等方法论，并辅以强大的SQL查询（Query & View 插件）、SuperRef 等思源独有的功能和插件，构建了一个高度灵活且可定制的个人知识管理系统，能够有效支持用户从零散的 Daily Notes 中自下而上地积累知识，并自上而下地组织成结构化的知识体系。
