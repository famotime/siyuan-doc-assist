# 灵动浮岛功能介绍

## 1. 功能概述

**灵动浮岛**是面向思源笔记桌面端的编辑器边缘悬浮辅助面板。开启后，会在当前文档编辑区边缘常驻一条轻量化的微型 Minimap 标尺；鼠标悬浮即可平滑展开浮岛面板，在不打断阅读与编辑的前提下，快速完成**文档大纲导航**、**已打开文档切换**以及**系统剪贴板历史管理**。

---

## 2. 通用交互与面板控制

- **Minimap 标尺与视口指示**：未展开时以极窄标尺形式贴合在编辑区边缘，实时映射文档内容分布与当前阅读视口位置，支持点击标尺快速定位。
- **悬浮展开与钉住固定**：鼠标移入标尺区域自动展开浮岛面板，移出后自动收起；点击右上角**钉住（Pin）**按钮可将面板固定常驻在编辑器一侧，方便持续对照浏览。
- **左右停靠切换**：支持在编辑器右侧与左侧之间一键切换停靠位置，并持久化记住你的停靠偏好。
- **多面板切换**：点击浮岛左上角标题按钮，可在已启用的面板之间灵活切换：
  - 仅启用 1 个面板时：直接固定显示该面板；
  - 启用 2 个面板时：点击标题即可双向切换；
  - 启用 3 个面板时：点击标题弹出轻量下拉菜单，一步直达目标面板。
- **实时搜索与拼音过滤**：顶部搜索框支持关键词实时过滤，并支持中文**拼音首字母**匹配；列表右上角实时显示当前命中数量与总条目数。

---

## 3. 三大功能面板

### 3.1 文档大纲

用于快速浏览当前文档结构并定位到目标位置：

- **层级标题大纲**：按文档层级缩进展示标题，支持与当前文档标题配色保持一致，并实时高亮当前阅读位置所在章节。
- **树形上下文模式**：搜索过滤时可切换是否保留命中节点的上级标题上下文，兼顾精准定位与结构感知。
- **快速跳转**：支持点击任意条目平滑跳转至对应块，顶部工具栏提供一键**置顶**与**置底**按钮。
- **跟随“关键内容”Dock**：在设置中开启「文档大纲跟随关键内容」后，该面板的展示内容会与侧栏「关键内容」Dock 当前选择的过滤类型（如标题、加粗、高亮、备注等）保持联动。

### 3.2 已打开文档

用于在多篇文档之间高频切换，无需在顶部标签栏中逐个寻找：

- **已打开文档列表**：展示当前窗口已打开的所有文档标签页，清晰标注激活状态与钉住（📌）状态，点击即可切换至对应文档。
- **最近文档分组**：在已打开文档下方提供「最近文档」分组，方便快速重新打开近期关闭或访问过的文档；两个分组均支持独立折叠与展开，并记忆折叠状态。
- **关键词与拼音检索**：支持按文档标题关键词或拼音首字母同时过滤已打开文档与最近文档。

### 3.3 剪贴板（桌面端专属）

面向桌面端提供后台静默剪贴板历史记录与复用能力，减少在文档与外部应用之间反复切换复制的成本：

- **多类型静默记录**：在桌面端后台自动捕获系统剪贴板中的**文本**、**图像**（如截图）以及从系统文件管理器复制的**文件/文件夹路径**（支持 Windows、macOS、Linux）。
- **去重与容量管理**：
  - 重复复制相同内容时自动去重，并将对应条目更新时间戳后置顶，同时保留原有收藏状态；
  - 非收藏记录默认最多保留 **200 条**，超出后按时间自动淘汰最旧记录并同步清理对应本地缓存图片；
  - **收藏（星标）条目永久保留**，不会被自动淘汰，也不会被「清空非收藏」清除。
- **分类过滤与搜索**：支持按 `全部`、`文本`、`图像`、`文件`、`收藏` 胶囊快速筛选，并支持结合顶部搜索框按文本内容、文件名或路径过滤。
- **单条预览与操作**：
  - 点击条目可展开或收起完整预览（完整文本、大图预览或完整文件路径列表），避免误触覆盖当前系统剪贴板；
  - 右侧提供显式操作按钮：**复制写回**、**收藏/取消收藏**、**删除**；文件条目还支持打开所在文件夹位置，若原文件已被移动或删除会给出提示。
- **批量处理模式**：支持开启批量选择（配合 `Ctrl` / `Shift` 快捷连选与全选），可对多条记录执行**合并复制**、**聚合为新条目**或**批量删除**，并支持一键**清空非收藏记录**。

## 4. 设置项说明

在插件设置页的 **灵动浮岛** 区域中，可统一配置以下选项：

1. **启用灵动浮岛**：控制是否在文档编辑区边缘显示灵动浮岛。关闭时，下方的子选项将同步置灰禁用。
2. **可切换面板**：多选配置要在浮岛左上角切换的面板（`文档大纲`、`已打开文档`、`剪贴板`，至少保留 1 项；默认启用 `文档大纲` 与 `已打开文档`）。仅当勾选 `剪贴板` 且处于桌面端时，才会启动后台剪贴板监听。
3. **文档大纲跟随关键内容**：开启后，「文档大纲」面板将同步跟随侧栏「关键内容」Dock 当前选中的过滤类型；关闭时默认展示层级标题大纲。

---

## 5. 平台支持与数据存储

- **桌面端专属**：受浏览器安全沙箱限制，灵动浮岛及后台剪贴板监听仅在思源笔记桌面端启用；在 Web 端或移动端环境下不会挂载浮岛或监听系统剪贴板。
- **本地存储位置**：剪贴板文本与元数据保存在插件标准数据文件 `clipboard-history.json` 中，捕获的内存图像以 PNG 形式缓存于插件存储目录 `clipboard-images/` 下；文件条目仅记录本地路径，不复制实体文件。
