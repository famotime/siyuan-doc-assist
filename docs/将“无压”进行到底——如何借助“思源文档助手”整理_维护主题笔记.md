# 将“无压”进行到底——如何借助“思源文档助手”整理、维护主题笔记

~思源笔记

## 楔子：剪藏一时爽，整理火葬场

自从使用思源笔记实践了 Daily Notes 工作流，我记笔记变的特别勤快。每天打开日记页面，脑子里冒出什么想法就随手写下来，给它加一个代表主题的双链标记，这条笔记在逻辑上就归属于那个主题了，完全不需要在记录的当下去纠结这条笔记该放到哪个文件夹。刷公众号看到一篇不错的文章，剪藏；在头条号发现一份有用的资料，剪藏；高手分享了一个值得研究的案例，剪藏。反正整理的事情以后再说，先记下来再说。

直到有一天，我打开一个持续积累了几个月的主题笔记，准备好好研究一下——才发现这份 MOC 已经面目全非了。有几条链接点进去是空的，对应的文档不知道什么时候被我清理掉了；从不同信息源剪藏的文章有好几篇标题不同但内容几乎一样；最近两个月新写的笔记明明加了相关的双链标记，却没有出现在这份主题笔记里。MOC 还停留在几个月前的样子，跟我笔记库的实际状况完全脱节了。

我知道该整理了，但一想到要从头梳理几十、上百条链接的关系——哪些该删、哪些该加、哪些该调整层次——就不想动了。记录的时候倒是"无压"了，整理的时候压力全堆在这儿了。正所谓"剪藏一时爽，整理火葬场"。

## 从"无压记录"到"无压整理"

Daily Notes + MOC 这套工作流的设计理念本身是没有问题的。Daily Notes 配合"传递型双链"，实现了"输入与整理分离"——在日记页面快速写下想法，加一个双链标记，这条笔记就在逻辑上归属于某个主题了。我不需要在记录的当下就考虑它该放在哪个文件夹，整理的事情推迟到以后，通过反链面板汇总查看就行，这种设计极大的降低了记录和剪藏时的心智负担。而 MOC 推崇"管理链接而非本体"——主题笔记里放的不是文档本身，而是文档的链接。一篇笔记可以同时出现在多个主题下，自然的实现了多维度的知识组织，这比传统文件夹系统的单一分类灵活多了。

问题出在哪儿呢？记录是一次性的动作，做完就完了；但整理和维护是持续性的工作。建立初版 MOC 也许不难，留出一段空闲时间下定决心，花个把小时就搞定了。但更大的挑战在于 MOC 的持续维护：新笔记在不断积累，旧笔记偶尔会被删除或合并，剪藏的文章可能有重复——如果每次整理都要从头来过，这个维护成本就成了压垮骆驼的最后一根稻草。

怎么让整理也变的"无压"呢？也许可以让"思源文档助手"（插件）帮助你减少一些阻碍。

## 建立你的初版主题笔记

假设你已经积累了一段时间的笔记，现在想把某个主题的笔记整理成一份 MOC。传统的做法是什么？手动一个一个找到相关文档，拖拽到主题笔记下面作为子文档，然后再回到主题笔记里把这些链接手动排列一下。如果相关文档有二三十篇，光是找和拖就够你忙活半天。

思源文档助手提供了 **"移动反链文档为子文档"** 和 **"移动正链文档为子文档"** 的便捷命令。大多数时候我就用链接关联四散的笔记文档，但对于某一个准备深入研究的主题，我还是习惯把关联文档都作为子文档，放在主题笔记节点之下。以前一个个拖拽太麻烦了，现在一个命令批量搞定。

文档归类好之后，下一步自然是在主题笔记里建立链接列表。你可以执行 **"插入子文档列表"** 或 **"插入反链文档列表"** 命令，一键在主题笔记中插入关联文档的链接。

还有一个小问题，主题笔记中该用链接还是引用？这个问题虽小，但也会给人造成摩擦和压力。有了 **"链接-引用批量互转"** 功能就不用纠结了，随手用链接或引用都行，反正随时可以一键互转。

## 让 MOC 保持常新

初次建立 MOC 也许不难，只需要留出一段空闲时间和下一次大决心，但更大的挑战在于 MOC 的持续维护和迭代。

笔记文档是逐步积累的。第一次建立的 MOC，过一段时间就不太符合笔记库的实际情况了：主题相关的新笔记增加了，来自头条号和公众号等不同信息源的剪藏文章可能有重复，还有些没有二次阅读价值的旧笔记可能已经被删掉了——但 MOC 并没有反映这些最新变化。怎么办呢，难道需要从头再来一次吗？

不需要。思源文档助手可以帮助你实现 MOC 的维护减少运动式的"大扫除"，只需要做增量整理。

 **"识别本层级重复文档"** 命令可以帮你找出同一层级下内容相似的文档。有时候从公众号、头条号不同数据源采集了很多文章准备有空了慢慢看，难免会保存重复文档。这个功能会把疑似重复的文档识别出来，你可以全部打开对比一下，再删除冗余的那些。

前面提到的 **"插入反链文档列表"** 和 **"插入子文档列表"** 在维护阶段同样好用。因为它们都支持去重，你只需要针对之前 MOC 不具备的新文档链接进行增量管理。我的习惯是隔一段时间就对常用的主题笔记执行一次，把新积累的关联文档补充进来，然后花几分钟调整一下它们在列表中的层次关系。每次只做一点增量整理，五分钟就够了，完全没有从头再来的压力。

主题文档是需要持续维护的，时间一长，难免会有一些链接指向了已经被删除的文档。 **"标示无效链接/引用"** 命令会批量识别 MOC 笔记中的所有失效链接和引用，并给它们打上删除线和高亮标记，你一眼就能看出哪些链接已经失效了，然后决定是删除还是寻找替代文档。每次仅清理无效链接，而无须从头检查所有链接，维护就轻松多了。

## 思源文档助手，将“无压”笔记进行到底

说到底，"无压"不是"不整理"。恰恰相反，"无压"的前提是你知道整理的门槛足够低，低到你随时可以轻松的做一点，而不是每次都要下定决心、腾出大块时间、做一次大扫除。

思源文档助手中“文档处理”的每一个功能，其实都在帮用户消除一个小小的阻碍——拖拽文档的麻烦，是阻碍；手动去重的重复劳动，是阻碍；纠结该用链接还是引用，是阻碍；不知道哪些链接已经失效了，也是阻碍。每消除一个阻碍，整理笔记的阻力就小一分，"无压"就更近一步。

希望思源笔记助手能帮助你将“无压”笔记进行到底，让你在通过记录笔记满足好奇心的同时，也能建立好自己的知识体系，收获满满的成果。
