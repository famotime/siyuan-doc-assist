# 灵动大纲剪贴板方案

## 1. 背景与可行性评估

在思源笔记桌面端（Electron 环境）中，插件运行于具备 Node.js 与 Electron 能力的渲染进程（可通过 `window.require("electron")` 获取原生模块）。

### 1.1 平台可行性
- **桌面端（Electron）完全可行**：
  - **文本与图像**：通过 `electron.clipboard.readText()`、`readImage()`、`writeText()`、`writeImage()` 可在不聚焦窗口的情况下后台静默捕获与写回。
  - **文件（从系统文件管理器复制）**：
    - Windows：通过 `clipboard.readBuffer("CF_HDROP")` 与 `clipboard.writeBuffer("CF_HDROP", buf)` 解析和构造原生 `DROPFILES` UTF-16LE 结构体，无需启动外部进程。
    - macOS：支持 `NSFilenamesPboardType`（或基础文本/图像降级）。
    - Linux：支持 `text/uri-list` 解析与写回。
- **Web 端与移动端受限**：受浏览器安全沙箱限制，无法在后台静默读取系统剪贴板。灵动大纲本身为桌面端专属特性，若在非桌面端触发则提示“剪贴板功能仅支持桌面端”。

### 1.2 风险与对策
- **自复制循环**：从剪贴板面板点击“复制”写回系统剪贴板时，记录本次写回的内容指纹（`suppressSignature`），后台轮询命中该指纹时跳过新增，避免重复入库。
- **性能与存储**：文本与元数据存入思源插件标准数据文件 `clipboard-history.json`（`loadData`/`saveData`）；内存图像（如截图）独立落盘为 PNG 文件至 `data/storage/petal/siyuan-doc-assist/clipboard-images/`，删除或超限淘汰时同步删除磁盘图片文件；文件条目仅记录本地路径列表，不复制实体文件。

## 2. 交互与功能设计

### 2.1 设置页可切换面板配置
在设置页「灵动大纲」分组中新增 **灵动大纲：可切换面板** 多选配置：
- 可选项：`文档大纲`、`已打开文档`、`剪贴板`
- 默认值：`["outline", "open-docs"]`（`剪贴板` 默认不勾选）
- **标题栏切换规则**：
  - 仅勾选 1 个面板：左上角标题不可切换，直接显示该面板；
  - 勾选 2 个面板：点击左上角标题按钮直接双向切换；
  - 勾选 3 个面板：点击左上角标题按钮弹出轻量下拉菜单，一步直达目标面板。
- **后台静默监听生命周期**：仅当设置中勾选了 `剪贴板` 且处于桌面端时，才启动后台静默剪贴板轮询（建议间隔 700ms）。

### 2.2 剪贴板视图 UI 与规范
- **图标与提示**：全部操作按钮使用 **Lucide 线框图标**；Tooltip 统一使用思源原生 `ariaLabel` 类 + `aria-label` + `data-position="parent"`，不叠加原生 `title` 属性以避免重复弹窗。
- **顶部工具栏**：隐藏文档专用的置顶、置底、树形上下文切换按钮；保留切换左右停靠、固定（Pin），并在剪贴板模式下提供「清空非收藏」按钮。
- **过滤与搜索**：
  - 复用现有搜索框：支持按文本内容、文件名或路径实时关键词过滤。
  - 下方过滤胶囊栏：`全部` | `文本` | `图像` | `文件` | `收藏`。
- **条目交互**：
  - 点击条目：**选中或展开/收起完整预览**（完整文本、大图预览、多文件完整路径列表），避免误触覆盖当前剪贴板。
  - 条目右侧显式按钮：**复制**、**收藏（星标）**、**删除**。
  - 复制文件条目时，若原路径已被移动或删除，给出提示而不写入无效路径。

### 2.3 存储与容量策略
- **去重与置顶**：若新捕获的内容与历史中某条指纹一致，将其 `updatedAt` 更新并移至列表顶部，保留原有 `id` 与收藏状态。
- **容量上限**：非收藏条目默认最多保留 **200 条**，超出后按最旧时间自动淘汰并清理对应落盘图片；**收藏条目永久保留不淘汰**。

## 3. 模块划分

| 层级 | 文件 | 职责 |
| :--- | :--- | :--- |
| **Core** | `src/core/dynamic-outline-core.ts` | 扩展 `DynamicOutlineViewMode` 增加 `"clipboard"`；扩展 `DynamicOutlineConfig.enabledViewModes` 与规范化逻辑。 |
| **Core** | `src/core/clipboard-core.ts` | 剪贴板数据模型、指纹计算、去重/淘汰逻辑、过滤与时间格式化纯函数。 |
| **Service** | `src/services/clipboard-monitor.ts` | Electron 剪贴板轮询、Windows `CF_HDROP` / Linux `text/uri-list` / macOS 文件路径解析与写回、图片落盘与清理、持久化适配器。 |
| **Plugin** | `src/plugin/plugin-lifecycle-state.ts` | 持久化 `dynamicOutlineViewModes` 配置。 |
| **Plugin** | `src/plugin/dynamic-outline-controller.ts` | 协调剪贴板数据同步至灵动大纲视图，处理复制/收藏/删除/清空回调。 |
| **Plugin** | `src/plugin/plugin-lifecycle.ts` | 管理后台静默监听启停，向设置页与控制器注入能力。 |
| **UI** | `src/ui/plugin-settings.ts` | 渲染「灵动大纲：可切换面板」多选配置。 |
| **UI** | `src/ui/dynamic-outline/dynamic-outline-view.ts` | 实现 1/2/3 面板标题切换（含下拉菜单）、剪贴板过滤栏、条目预览与显式操作按钮。 |
| **Styles** | `src/styles/_dynamic-outline.scss` | 下拉菜单、剪贴板过滤胶囊、条目卡片、大图/文本预览及操作按钮样式。 |
| **Tests** | `tests/clipboard-core.test.ts`、`tests/clipboard-monitor.test.ts`、`tests/dynamic-outline-core.test.ts` | 核心纯逻辑、去重淘汰、过滤、`CF_HDROP` 编解码与多面板配置单测。 |
