# 思源笔记文档助手 (Doc Assist)

> 协助你整理笔记的好帮手 —— 让关键信息一目了然，让笔记整理一键完成。

## 💡 为什么需要文档助手？

在日常使用思源笔记的过程中，你是否经常遇到以下困扰：

- **重点散落，难以统揽**：阅读长文时做了许多高亮、加粗、标签与备注，读完后想纵览全貌或提取清单，却不得不从头到尾反复翻滚页面；
- **剪藏内容，排版凌乱**：从网页、公众号或 AI 工具（如 Deep Research 报告）导入的内容，充斥着广告尾巴、断裂列表、脚注编号、多余空行与混乱标点，手工清理耗时费力；
- **网状链接，缺乏结构**：双链虽好，但当需要围绕某个专题深挖时，四散的正反链文档难以快速归整为清晰的层级树；
- **对照写作，频繁切屏**：边看参考资料边写总结，单屏幕下窗口来回切换令人疲惫。

**思源笔记文档助手**正是为了解决这些真实场景中的痛点而设计。它不改变思源笔记原本优秀的使用习惯，而是在侧边栏、右键菜单和快捷面板中，为你提供一套高效、顺手的“文档加工流水线”。



## 🎯 核心使用场景与用户价值

### 场景一：长文精读与重点提炼 —— 告别“划了重点就沉睡”

**【痛点】** 划了再多重点，如果不做聚合，最终都会沉睡在正文的各个角落；想回顾或导出大纲极其繁琐。

**【助手方案】**
- **全要素关键信息提取**：侧边栏自动聚合当前文档中的**标题、加粗、高亮（含字体色/背景色/整段颜色）、斜体、下划线、代码块、备注、标签、双链与引用**。
- **灵活多维筛选**：支持按类型多选筛选（如仅看“高亮+备注”或“加粗+标题”），同段关键内容智能合并，支持折叠与即时刷新。
- **一键平滑跳转**：点击侧栏中的任意要点条目，正文瞬间平滑滚动并准确定位到对应块，复习与检索行云流水。
- **重点一键导出 / 转化为导图**：将筛选出的核心内容一键复制/导出为结构化 Markdown，或联动“无界”画布插件一键生成 Canvas 概念导图。

### 场景二：网页剪藏与 AI 报告清洗 —— 格式噪音一键抚平

**【痛点】** 网页剪藏带来的公众号版权声明、打赏引流段落，以及 AI 深度研究（Deep Research）生成的杂乱脚注（如 `[1]`、`^^`、来源超链接），手动删改非常消磨耐心。

**【助手方案】**

- **一键断尾求真（删除后续段落）**：光标停在正文结尾处，一键删除后续所有宣传引流段落；配合「删除之前段落」（智能保护文首概要），去头去尾只需数秒。
- **清理 AI 报告残留**：一键去除 Deep Research 类报告中的脚注上标、隐藏引用标记、来源链接等噪音字符。
- **排版强迫症修复套装**：
  - **清理剪藏内容**：自动合并断裂列表项，抹除冗余序号前缀，规范中英混排段落；
  - **去除空段落 / 行尾空格**：消除不规范换行与末尾空白符，瞬间让长文紧凑清爽；
  - **中英文标点互转 / 选中删除空格**：一键解决标点混用与奇怪的零宽字符问题；
  - **段落与换行互转 / 列表合并**：轻松在多行文字与独立块之间相互转换。
- **安全可逆**：核心编辑命令深度接入撤销恢复机制，支持常规快捷键 `Ctrl + Z` 回退，大胆整理无顾虑。



### 场景三：双链网状整理与主题沉淀 —— 零散关联升级为系统专题

**【痛点】** 日常记录依赖网状双链，但当准备把一个主题系统化、沉淀为专题知识库时，四散的关联文档难以归拢；维护链接时反复插入导致重复凌乱。

**【助手方案】**

- **关联文档一键结构化（移动为子文档）**：将分散在笔记本各处的反向链接或正向链接文档，一键批量移动到当前主题文档之下，迅速建立整洁的树状知识体系。
- **智能增量插入（去重）**：
  - 「插入反链列表 / 插入子文档列表」：自动比对正文已有链接，**仅追加尚未出现的新文档链接**，保护你已经精心排版的主题索引，增量更新毫无负担。
- **链接与引用自如切换**：
  - **链接 ⇋ 引用批量互转**：无需再纠结当前应该用超链接还是思源引用，支持全文自动检测并一键双向转换；
  - **标示无效链接/引用**：自动扫描文档，给失效的死链添加删除线和高亮，知识库健康度体检一目了然。
- **重复文档识别与大文件盘点**：
  - **识别同层级重复文档**：采集同一主题文章时避免重复保存，智能比对相似度并支持对比后快速合并删除；
  - **Top 100 大文件报告**：一键扫描并列出占用空间最大的前 100 篇文档及资源，方便知识库瘦身。



### 场景四：AI 深度赋能 —— 翻译、识图、摘要与构思跃迁

**【痛点】** 外文资料对照阅读吃力、图片中的文字无法被搜索、写完长文起不出贴切标题。

**【助手方案】**（兼容任何 OpenAI 标准格式的 API 接口，随开随用）：
- **本文档逐段翻译**：针对包含英文的段落进行 AI 翻译，并在原段落下方优雅插入中文译文，实现沉浸式双语对照精读。
- **图片文字识别 (OCR)**：一键识别正文或选区中的图片（支持超长长图自动切片），将提取的文字以引用格式直接插入图片下方，图片内容从此可被全局索引检索。
- **AI 拟定“更好的标题”**：结合全文深度语境，一次性提炼 6 组高质量标题候选（兼顾抓人眼球与平实概括），支持弹窗快速微调并一键替换。
- **一键生成文档摘要 / 概念地图**：后台静默生成核心摘要插入文首；或串联子文档与正反链资料，一键输出层次化概念地图。
- **生态联动**：深度配合“脉络镜”插件，自动推荐关联双链、生成标签体系及 LLM Wiki。



### 场景五：多任务对照写作 —— 桌面置顶悬浮窗

**【痛点】** 边看大纲边查资料、对照视频做笔记，或者写代码时需要盯住某个接口文档，反复 `Alt + Tab` 切换切断心流。

**【助手方案】**
- **独立置顶浮窗 (Floating Window)**：将选中的关键段落或整篇文档一键投射为桌面顶层的小巧悬浮窗。
- **完整渲染与即时编辑**：半透明无边框设计，支持完整 Markdown 渲染（多级列表、待办复选框、代码块与图片），支持纯文本与渲染视图切换，随时可复制、可编辑、可调整透明度，随时伴随你的跨软件工作流。



### 场景六：资源瘦身与图片智能优化

**【痛点】** 复制网页图片或手机高清截图导致笔记本资产库（assets）迅速膨胀到几十个 G，备份慢、云同步痛苦。

**【助手方案】**
- **批量转换为 WebP / PNG**：利用现代化 WebP 格式压缩文档内置图片，体积立减 60%~80% 且画质肉眼无损。
- **按当前显示尺寸重采样**：许多图片仅以 400px 宽度显示，后台却存储了 4000px 的原图。该功能可自动按实际显示尺寸缩放重存，杜绝无效浪费。
- **删除本文档图片**：一键去除所有图片链接与图片块，秒变纯文本版。

## ⚠️ 重要说明与建议

- **数据安全建议**：“文档处理”中的部分整理与编辑命令涉及文档内容批量变更或文档树层级变动。虽然核心文本清理命令已支持 `Ctrl + Z` 撤销，但仍建议在对重要知识库执行大范围重构时，善用思源笔记自带的**云端同步快照**或**文档数据历史**作为双重保障。
- **关于环境兼容**：部分涉及本地文件移动的层级整理功能在桌面端体验更佳；涉及无界画布和脉络镜联动的特性需要预先安装对应的协同插件。
